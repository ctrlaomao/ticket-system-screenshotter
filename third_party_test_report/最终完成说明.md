## 💻 技术实现

### 核心脚本
**`capture_ota_tabs.py`** - OTA平台Tab智能截图脚本

主要功能：
1. 自动登录系统
2. 访问设置页面
3. 智能识别并点击"OTA平台"选项
4. 依次查找并点击三个平台的Tab
5. 对每个Tab进行全页截图
6. 自动应用敏感信息打码
7. 删除原始截图确保安全

### 关键技术
- **Playwright** - 浏览器自动化，支持Tab切换
- **PIL/Pillow** - 图像处理和智能打码
- **多选择器策略** - 确保能找到Tab元素
- **安全清理** - 自动删除原始截图

### 代码特点
```python
# 智能Tab查找
tab_selectors = [
    f"text={keyword}",
    f"[role='tab']:has-text('{keyword}')",
    f".tab:has-text('{keyword}')",
    f".nav-link:has-text('{keyword}')",
    # ... 更多选择器策略
]

# 自动打码
mask_regions = [
    (x1, y1, x2, y2, "AppID/应用ID"),
    (x1, y1, x2, y2, "AppSecret/密钥"),
    # ... 更多遮罩区域
]
```
